# Mermaid Radio Website

Responsive React + Tailwind CSS website concept.

## Pages
- `/` — Landing page and Our Values
- `/catalogue` — Catalogue
- `/products/:id` — Product/show detail pages
- `/contact` — Customer support contact form (demo only)
- `/privacy` — Privacy policy starter template

## Run locally
1. Install Node.js LTS.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL printed by Vite.

Build with `npm run build`.

## Before publishing
- Replace sample shows with Mermaid's actual catalogue.
- Connect the contact form to a backend or form service. It currently does not send or store messages.
- Review and replace the privacy policy with one matching the real business and data practices.
- Add official support email and company details.
- Google Fonts are loaded remotely; system fallbacks are included.
